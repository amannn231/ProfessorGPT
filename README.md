**🎓 ProfessorGPT – AI Powered Academic Assistant
**
ProfessorGPT is an AI-based educational assistant built using **Streamlit** and **Google Gemini API**.  
It provides intelligent, subject-specific answers tailored to different academic levels and also converts responses into speech.

**🚀 Features
**
- 📚 Subject-based question answering
- 🎓 Academic level customization (High School to PhD)
- 🤖 Powered by Google Gemini AI
- 🔊 Text-to-Speech (TTS) Audio Response
- 🌙 Dark / Light Mode Toggle
- 🎨 Clean and Interactive UI

**🛠️ Tech Stack
**
- Python
- Streamlit
- Google Generative AI (Gemini API)
- Wave & IO (for audio formatting)
